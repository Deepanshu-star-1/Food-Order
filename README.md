🍽 Food@Home
Food@Home is a web-based food ordering application built with HTML, CSS, and JavaScript. This platform enables users to browse menus, add food items to their cart, and place orders through a responsive and user-friendly interface.

🔥 Features
Responsive Design: Seamless experience across desktop, tablet, and mobile devices

Menu Browsing: Interactive menu with categories, images, and item details

Cart Functionality: Add/remove items, update quantity, view total price

User Authentication: Signup and login system for personalized orders

Order Tracking: Real-time order summary and status

Multiple Pages: Includes Home, Menu, About Us, Contact, and Checkout pages

Error Handling: Custom 404 error page for non-existent routes

Order History: Users can view past orders and details

🛠 Tech Stack
Frontend: HTML5, CSS3, JavaScript

UI Design: Custom CSS with responsive layout

Data Handling: JSON to simulate product and order data

Interactions: JavaScript for dynamic cart and UI behavior
